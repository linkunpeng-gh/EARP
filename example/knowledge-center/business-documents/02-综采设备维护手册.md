# 综采设备维护手册

## 第一章 总则

### 1.1 目的
为规范综采设备的维护保养工作，提高设备完好率和可用率，降低设备故障率，保障采煤工作面正常生产，制定本手册。

### 1.2 适用范围
本手册适用于综合机械化采煤工作面的主要设备，包括采煤机、液压支架、刮板输送机、转载机、破碎机、乳化液泵站等设备的日常维护、定期检修和故障处理。

### 1.3 维护原则
坚持"预防为主、计划检修、按需维护"的原则，实行设备包机制度，每台设备明确责任人，做到台台设备有人管。

## 第二章 采煤机维护

### 2.1 日常检查（每班）
1. **外观检查**：检查采煤机外观有无损伤、漏油、漏水现象，各连接螺栓是否紧固。
2. **截割部检查**：检查截齿磨损情况，磨损严重的截齿必须及时更换；检查截割滚筒转动是否灵活，有无异常声响。
3. **牵引部检查**：检查牵引链或销排有无断裂、变形，牵引速度是否正常。
4. **液压系统检查**：检查液压油位是否正常，液压系统有无渗漏，各操作阀动作是否灵活可靠。
5. **冷却系统检查**：检查冷却水流量是否正常，水路有无堵塞或泄漏。
6. **电气系统检查**：检查各电缆接头是否牢固，有无破损，控制按钮、显示屏工作是否正常。

### 2.2 定期维护（每周）
1. 更换磨损严重的截齿和齿座，保证截割效率。
2. 检查并调整牵引链张紧度，销排连接螺栓紧固。
3. 清洗液压系统过滤器，检查液压油质量，必要时补充或更换液压油。
4. 检查各润滑点润滑情况，按润滑图表加注润滑脂。
5. 检查制动器制动性能，调整制动间隙。
6. 检查电气系统绝缘性能，清理电气箱内灰尘。

### 2.3 月度检修
1. 拆检截割部齿轮箱，检查齿轮、轴承磨损情况，更换齿轮油。
2. 拆检牵引部传动机构，检查牵引链条磨损量，超过磨损极限的必须更换。
3. 检查液压泵、液压马达性能，测试系统压力是否符合要求。
4. 检查冷却系统，清洗冷却器，保证散热效果。
5. 对电气系统进行全面检查，测试各保护装置动作可靠性。
6. 进行整机性能测试，检查截割高度、牵引速度、装机功率等参数是否符合设计要求。

### 2.4 常见故障及处理

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 采煤机不能牵引 | 牵引链断裂/液压系统压力低/制动器未松开 | 更换牵引链/检查液压泵和溢流阀/检查制动器控制油路 |
| 截割部异响 | 齿轮磨损/轴承损坏/缺油 | 停机检查，更换损坏件，补充齿轮油 |
| 液压系统温度过高 | 冷却水量不足/液压油粘度不对/系统内泄大 | 增大冷却水量/更换合适粘度液压油/检查液压元件内泄 |
| 摇臂升降缓慢 | 液压油位低/液压缸内泄/操纵阀磨损 | 补充液压油/更换液压缸密封/检修或更换操纵阀 |

## 第三章 液压支架维护

### 3.1 日常检查（每班）
1. 检查支架接顶情况，支架必须接顶严实，初撑力达到规定值。
2. 检查立柱、千斤顶有无渗漏，活塞杆有无划伤、锈蚀。
3. 检查各液压管路连接是否牢固，有无破损、漏液。
4. 检查操纵阀动作是否灵活，各阀组有无漏液。
5. 检查推移杆、连接头有无变形、裂纹。
6. 检查侧护板、护帮板动作是否正常。

### 3.2 定期维护（每周）
1. 检查并紧固各连接螺栓，特别是推移连接销、侧护板连接销。
2. 检查立柱、千斤顶密封性能，有渗漏的及时更换密封件。
3. 清洗过滤器，检查乳化液浓度，保证浓度在3%-5%范围内。
4. 检查安全阀动作压力，不合格的及时调整或更换。
5. 对各铰接点加注润滑脂。

### 3.3 月度检修
1. 对立柱、千斤顶进行性能测试，检查内泄情况，内泄超标的更换密封件。
2. 对操纵阀、控制阀组进行拆检，清洗阀件，更换磨损的阀芯和密封。
3. 检查推移框架、推杆有无变形、裂纹，必要时进行修复或更换。
4. 检查侧护板、护帮板、尾梁等结构件有无开焊、变形。
5. 更换老化的液压胶管，检查高压胶管的压力等级是否符合要求。
6. 对整架进行动作试验，检查升柱、降柱、推溜、拉架、侧护、护帮等动作是否正常。

### 3.4 乳化液管理
1. 乳化液浓度必须保持在3%-5%，每班检查浓度，使用折光仪测量。
2. 乳化液必须使用规定牌号的乳化油，严禁使用不合格的乳化油。
3. 乳化液箱必须加盖，防止污染，定期清洗乳化液箱和过滤器。
4. 乳化液温度不得超过50℃，超过时必须查明原因并处理。
5. 定期检测乳化液的pH值、防锈性、稳定性等指标。

## 第四章 刮板输送机维护

### 4.1 日常检查（每班）
1. 检查刮板链运行情况，有无跳链、飘链、卡链现象。
2. 检查刮板、连接环有无变形、断裂、磨损严重。
3. 检查链条张紧度，机头、机尾链轮啮合是否正常。
4. 检查减速器油位、油温，有无异常声响和渗漏。
5. 检查液力偶合器充液量，有无渗漏，易熔塞是否完好。
6. 检查各连接螺栓是否紧固，特别是机头、机尾架连接螺栓。
7. 检查铲煤板、挡煤板有无变形、缺失。

### 4.2 定期维护（每周）
1. 检查链条磨损量，测量链条伸长率，超过2.5%时必须更换。
2. 检查刮板磨损情况，磨损严重的及时更换，保证刮板间距符合要求。
3. 检查减速器齿轮油质量，必要时补充或更换。
4. 检查液力偶合器，按规定补充工作液体，检查易熔塞和防爆塞。
5. 紧链，调整链条张紧度，保证机头下方垂度合适。
6. 检查机头、机尾锚固装置是否牢固。

### 4.3 月度检修
1. 拆检减速器，检查齿轮、轴承磨损情况，更换齿轮油和密封件。
2. 检查链轮轴组，测量链轮磨损量，磨损超标的更换链轮。
3. 检查中间槽、过渡槽磨损情况，底板磨损严重的及时更换。
4. 检查机头架、机尾架有无变形、开焊。
5. 更换磨损严重的刮板、连接环、螺栓。
6. 进行整机试运行，检查运行平稳性，有无异常声响。

## 第五章 设备完好标准

### 5.1 采煤机完好标准
1. 机体：机壳、盖板无裂纹，连接螺栓齐全紧固。
2. 截割部：齿轮传动平稳，无异响，油温不超过75℃，截齿齐全锋利。
3. 牵引部：牵引链或销排完好，牵引速度正常，制动器灵敏可靠。
4. 液压系统：压力正常，无渗漏，操纵阀动作灵活，液压缸无内泄。
5. 冷却喷雾：冷却水路畅通，喷雾效果良好。
6. 电气系统：绝缘良好，保护齐全可靠，电缆悬挂整齐。

### 5.2 液压支架完好标准
1. 结构件：顶梁、掩护梁、底座无开焊、无严重变形。
2. 立柱千斤顶：无渗漏，活塞杆无严重划伤，动作灵活可靠。
3. 阀组：操纵阀、控制阀、安全阀动作灵敏，无漏液，压力符合规定。
4. 管路：液压胶管无破损、无老化，连接牢固，排列整齐。
5. 推移装置：推杆、连接头无变形、无裂纹，连接可靠。
6. 乳化液：浓度3%-5%，清洁无杂质。

### 5.3 刮板输送机完好标准
1. 机头机尾：架体无变形，锚固可靠，减速器无渗漏、无异响。
2. 链轮组件：链轮磨损不超限，转动灵活，轴承无异响。
3. 刮板链：刮板齐全，连接环无变形，链条伸长率不超过2.5%。
4. 溜槽：中部槽、过渡槽无严重变形，底板磨损不超限。
5. 保护装置：液力偶合器易熔塞、防爆塞齐全，过载保护可靠。
6. 电气设备：电动机绝缘良好，控制保护齐全，电缆悬挂整齐。

## 第六章 维护记录与考核

### 6.1 维护记录
设备维护必须做好记录，包括日常检查记录、定期维护记录、月度检修记录、故障处理记录。记录内容应包括：设备编号、维护日期、维护内容、发现问题、处理措施、维护人等。

### 6.2 设备考核
建立设备完好率、可用率、故障率考核指标：
- 设备完好率 = 完好设备台数 / 设备总台数 × 100%，要求达到95%以上
- 设备可用率 = 设备实际可用时间 / 设备制度工作时间 × 100%，要求达到90%以上
- 设备故障率 = 设备故障停机时间 / 设备制度工作时间 × 100%，要求控制在5%以下

### 6.3 备品备件管理
建立设备备品备件台账，根据设备磨损规律和故障统计，合理储备易损件和关键备件，保证维修需要。备品备件必须定期检查，保证质量合格。
