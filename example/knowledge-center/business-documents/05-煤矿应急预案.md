# 煤矿应急预案

## 第一章 总则

### 1.1 编制目的
为规范煤矿生产安全事故的应急管理和应急响应程序，及时有效地实施应急救援工作，最大程度地减少人员伤亡和财产损失，保障员工生命安全和企业财产安全，维护社会稳定，制定本预案。

### 1.2 编制依据
依据《中华人民共和国安全生产法》《中华人民共和国突发事件应对法》《生产安全事故报告和调查处理条例》《煤矿安全规程》《生产经营单位安全生产事故应急预案编制导则》等法律法规和标准，结合本矿实际，制定本预案。

### 1.3 适用范围
本预案适用于本矿范围内发生的各类生产安全事故的应急救援工作，包括瓦斯爆炸、煤尘爆炸、火灾、水灾、顶板事故、机电运输事故、中毒窒息等事故类型。

### 1.4 工作原则
1. **以人为本，安全第一**：把保障员工生命安全作为应急救援工作的首要任务，最大限度地减少人员伤亡。
2. **统一领导，分级负责**：在矿应急救援指挥部的统一领导下，各部门、各单位按照职责分工，分级负责，协同作战。
3. **预防为主，平战结合**：坚持预防与应急相结合，常态与非常态相结合，做好日常应急准备工作。
4. **快速反应，果断处置**：事故发生后，迅速启动应急预案，果断采取有效措施，控制事态发展。
5. **依靠科学，依法规范**：采用先进的应急救援技术和装备，依法规范应急救援工作。

## 第二章 应急组织机构及职责

### 2.1 应急救援指挥部
成立矿应急救援指挥部，由矿长任总指挥，各分管副矿长任副总指挥，各部门负责人为成员。

**指挥部职责**：
1. 贯彻落实国家有关应急救援工作的法律法规和政策。
2. 统一领导和指挥全矿应急救援工作。
3. 决定启动和终止应急预案。
4. 制定应急救援方案，指挥协调各应急救援小组开展工作。
5. 负责应急救援物资、装备、人员的调配。
6. 负责事故信息的上报和发布。
7. 负责事故善后处理和事故调查配合工作。

### 2.2 应急救援办公室
应急救援指挥部下设办公室，办公室设在安全管理部门，由安全管理部门负责人任办公室主任。

**办公室职责**：
1. 负责应急预案的编制、修订和演练工作。
2. 负责应急救援日常管理工作，建立健全应急救援台账。
3. 负责应急救援物资、装备的储备和管理。
4. 负责事故信息的接收、汇总和上报。
5. 负责应急救援通讯联络工作。
6. 负责应急救援培训和宣传教育工作。

### 2.3 应急救援小组
指挥部下设若干应急救援小组：

1. **现场抢险组**：由生产技术部门牵头，负责现场抢险救援工作，包括人员搜救、险情控制、工程抢险等。
2. **医疗救护组**：由医务部门牵头，负责受伤人员的现场急救和医疗转运工作。
3. **通风保障组**：由通风部门牵头，负责矿井通风系统的调整和恢复，保障灾区通风安全。
4. **机电保障组**：由机电部门牵头，负责应急供电、排水、提升等系统的保障和恢复。
5. **安全监测组**：由安全监测部门牵头，负责灾区气体监测、环境监测，为抢险救援提供数据支撑。
6. **后勤保障组**：由后勤部门牵头，负责应急救援物资、装备、食品、饮用水等的供应和运输保障。
7. **治安保卫组**：由保卫部门牵头，负责事故现场的治安保卫、交通管制、人员疏散等工作。
8. **善后处理组**：由工会和人力资源部门牵头，负责伤亡人员家属的安抚、赔偿等善后处理工作。
9. **信息发布组**：由宣传部门牵头，负责事故信息的发布和媒体沟通工作。

## 第三章 事故类型及风险分析

### 3.1 瓦斯爆炸事故
**风险分析**：瓦斯爆炸是煤矿最严重的事故类型之一，具有突发性强、破坏力大、伤亡严重的特点。瓦斯爆炸必须同时具备三个条件：瓦斯浓度在爆炸界限内（5%-16%）、高温火源（650-750℃以上）、氧气浓度大于12%。

**可能发生地点**：采煤工作面、掘进工作面、回风巷、盲巷、采空区等瓦斯容易积聚的地点。

### 3.2 煤尘爆炸事故
**风险分析**：煤尘爆炸是煤矿重大事故类型，煤尘爆炸必须同时具备四个条件：煤尘本身具有爆炸性、煤尘悬浮在空气中并达到一定浓度（45-2000g/m³）、高温火源（610-1050℃以上）、氧气浓度大于17%。

**可能发生地点**：采煤工作面、掘进工作面、运输巷、回风巷等煤尘容易积聚的地点。

### 3.3 火灾事故
**风险分析**：煤矿火灾分为外因火灾和内因火灾。外因火灾是指由于外部火源引起的火灾，如电气火灾、爆破火灾、摩擦火灾等；内因火灾是指煤炭自身氧化发热引起的自燃火灾。

**可能发生地点**：
- 外因火灾：机电硐室、皮带运输巷、采掘工作面、油库等。
- 内因火灾：采空区、煤柱、巷道顶煤、采掘工作面等。

### 3.4 水灾事故
**风险分析**：煤矿水灾是指矿井在建设和生产过程中，地表水、地下水、老空水等通过各种通道涌入矿井，造成人员伤亡和财产损失的事故。

**可能发生地点**：采掘工作面、巷道、井底车场、采空区附近等。

### 3.5 顶板事故
**风险分析**：顶板事故是指在采掘过程中，顶板岩石冒落、片帮等造成的人员伤亡和财产损失事故。顶板事故是煤矿最常见的事故类型。

**可能发生地点**：采煤工作面、掘进工作面、巷道交叉口、大断面硐室等。

### 3.6 机电运输事故
**风险分析**：机电运输事故是指机电设备故障、运输设备事故等造成的人员伤亡和财产损失事故。

**可能发生地点**：机电硐室、运输线路、采掘工作面、提升系统等。

### 3.7 中毒窒息事故
**风险分析**：中毒窒息事故是指井下有毒有害气体（一氧化碳、硫化氢、二氧化氮等）浓度超标或氧气浓度过低，造成人员中毒或窒息的事故。

**可能发生地点**：火灾灾区、爆破后工作面、盲巷、采空区、密闭附近等。

## 第四章 预防与预警

### 4.1 事故预防
1. **瓦斯事故预防**：加强通风管理，保证矿井通风系统稳定可靠；加强瓦斯检查和监测，及时发现和处理瓦斯积聚；严格执行瓦斯管理制度，严禁瓦斯超限作业；加强火源管理，严禁井下吸烟、明火。
2. **煤尘事故预防**：加强综合防尘管理，采取湿式钻眼、洒水降尘、喷雾降尘、通风除尘等措施；定期冲洗巷道积尘；加强煤尘爆炸性鉴定；严格执行爆破管理制度。
3. **火灾事故预防**：加强外因火灾预防，严格执行电气设备防爆标准，加强机电设备维护，严禁违章用电；加强内因火灾预防，建立自然发火预测预报制度，加强采空区管理，及时封闭采空区。
4. **水灾事故预防**：加强水文地质工作，查明矿井水文地质条件；坚持"预测预报、有疑必探、先探后掘、先治后采"的防治水原则；加强排水系统建设，保证排水能力；加强地表水体治理。
5. **顶板事故预防**：加强顶板管理，严格执行敲帮问顶制度；加强支护质量检查，保证支护强度；加强矿压观测，掌握顶板活动规律；严格执行作业规程。
6. **机电运输事故预防**：加强机电设备管理，保证设备完好；加强运输设备管理，严格执行运输操作规程；加强安全保护装置检查，保证保护齐全可靠。
7. **中毒窒息事故预防**：加强通风管理，保证井下空气符合标准；加强有毒有害气体监测；严格执行密闭管理制度，严禁擅自进入盲巷和密闭区。

### 4.2 预警机制
1. **监测预警**：建立安全监控系统，对瓦斯、一氧化碳、温度、风速等参数进行实时监测，发现异常及时预警。
2. **人工巡查预警**：建立安全巡查制度，各级管理人员和岗位人员定期巡查，发现隐患及时报告和处理。
3. **预警级别**：根据事故的紧急程度、发展态势和可能造成的危害程度，预警级别分为一级（特别严重）、二级（严重）、三级（较重）、四级（一般），分别用红色、橙色、黄色、蓝色表示。
4. **预警发布**：预警信息通过调度电话、广播、短信、警报等方式发布，确保相关人员及时收到预警信息。
5. **预警响应**：接到预警信息后，相关部门和人员必须立即采取防范措施，做好应急准备。

## 第五章 应急响应

### 5.1 事故报告
1. **报告时限**：事故发生后，现场人员必须立即报告矿调度室，调度室接到报告后必须立即报告矿领导，并在1小时内向上级主管部门和当地政府报告。
2. **报告内容**：事故发生的时间、地点、事故类型、伤亡情况、事故简要经过、已采取的措施、需要支援的事项等。
3. **报告要求**：事故报告必须及时、准确、完整，不得迟报、漏报、谎报、瞒报。

### 5.2 响应分级
根据事故的严重程度和影响范围，应急响应分为四级：
1. **一级响应（特别重大事故）**：造成30人以上死亡，或者100人以上重伤，或者1亿元以上直接经济损失的事故。
2. **二级响应（重大事故）**：造成10人以上30人以下死亡，或者50人以上100人以下重伤，或者5000万元以上1亿元以下直接经济损失的事故。
3. **三级响应（较大事故）**：造成3人以上10人以下死亡，或者10人以上50人以下重伤，或者1000万元以上5000万元以下直接经济损失的事故。
4. **四级响应（一般事故）**：造成3人以下死亡，或者10人以下重伤，或者1000万元以下直接经济损失的事故。

### 5.3 响应程序
1. **接警与响应**：调度室接到事故报告后，立即报告应急救援指挥部，总指挥根据事故情况决定启动相应级别的应急预案。
2. **应急启动**：应急预案启动后，应急救援指挥部成员和各应急救援小组必须立即赶赴事故现场，按照职责分工开展应急救援工作。
3. **灾情侦察**：安全监测组和现场抢险组必须迅速查明事故情况，包括事故地点、事故类型、伤亡情况、灾区范围、气体情况、通风情况等，为制定救援方案提供依据。
4. **制定方案**：应急救援指挥部根据灾情侦察结果，制定应急救援方案，明确救援任务、救援方法、安全措施、人员分工等。
5. **组织实施**：各应急救援小组按照救援方案，迅速开展抢险救援工作。
6. **应急升级**：当事故事态扩大，超出本级应急救援能力时，必须及时向上级应急救援机构请求支援，升级应急响应级别。
7. **应急终止**：当事故得到有效控制，伤亡人员全部救出，现场险情消除，经应急救援指挥部确认后，终止应急响应。

## 第六章 专项应急处置

### 6.1 瓦斯爆炸事故应急处置
1. 立即切断灾区电源，防止二次爆炸。
2. 迅速恢复灾区通风，排除爆炸产生的有毒有害气体。
3. 组织人员搜救遇难人员，优先抢救受伤人员。
4. 加强灾区气体监测，防止瓦斯再次积聚和爆炸。
5. 清理爆炸现场，修复损坏的巷道和设备。
6. 查明事故原因，防止类似事故再次发生。

### 6.2 火灾事故应急处置
1. **外因火灾处置**：
   - 立即切断灾区电源，防止火势蔓延。
   - 迅速组织人员利用灭火器材灭火，控制火势。
   - 调整通风系统，防止火灾气体蔓延到其他区域。
   - 火势较大无法直接灭火时，必须立即组织人员撤离，封闭火区。
2. **内因火灾处置**：
   - 发现自然发火征兆后，立即报告，采取措施处理。
   - 调整通风系统，减少向火区供风。
   - 采取注浆、注氮、灌浆等灭火措施。
   - 火区范围较大时，封闭火区，采取综合灭火措施。
   - 火区熄灭后，必须经过取样化验确认，方可启封。

### 6.3 水灾事故应急处置
1. 立即组织受水害威胁区域的人员撤离到安全地点。
2. 迅速启动排水设备，加大排水力度。
3. 查明水灾来源，采取堵截措施，防止水量增大。
4. 加强通风，排除井下有毒有害气体。
5. 组织人员搜救被困人员，为被困人员输送食品、饮用水和空气。
6. 修复损坏的巷道和设备，恢复生产。

### 6.4 顶板事故应急处置
1. 立即停止作业，组织人员撤离到安全地点。
2. 查明事故情况，确定被埋压人员位置。
3. 采取支护措施，加固周围顶板，防止二次冒顶。
4. 组织人员清理冒落物，抢救被埋压人员。
5. 抢救人员时必须使用专用工具，严禁用镐刨、锤砸，防止伤害被埋压人员。
6. 对受伤人员进行现场急救，及时送往医院治疗。

### 6.5 机电运输事故应急处置
1. 立即停止设备运行，切断电源。
2. 组织人员抢救受伤人员。
3. 查明事故原因，采取措施防止事故扩大。
4. 修复损坏的设备和设施，恢复正常运行。
5. 加强设备检查，消除安全隐患。

## 第七章 应急保障

### 7.1 队伍保障
建立专职应急救援队伍，配备专业救援人员和装备。同时建立兼职应急救援队伍，由各生产单位骨干人员组成，定期进行培训和演练。

### 7.2 物资保障
建立应急救援物资储备库，储备足够的应急救援物资和装备，包括：
1. 通风设备：局部通风机、风筒、风门等。
2. 排水设备：水泵、排水管、水带等。
3. 支护材料：锚杆、锚索、工字钢、木板等。
4. 灭火器材：灭火器、灭火弹、注浆设备、注氮设备等。
5. 急救器材：担架、急救箱、氧气呼吸器、自救器等。
6. 通讯设备：对讲机、应急电话、广播设备等。
7. 照明设备：应急灯、矿灯、探照灯等。
8. 运输设备：救护车、运输车、矿用卡车等。

### 7.3 通讯保障
建立完善的应急通讯系统，保证应急救援期间通讯畅通。井下必须安装应急电话系统，重要地点必须配备对讲机。应急救援指挥部成员必须保持24小时通讯畅通。

### 7.4 医疗保障
建立矿医务室，配备专业医务人员和急救药品、器材。与附近医院建立医疗救援合作关系，确保重伤人员能够及时得到医疗救治。

### 7.5 交通保障
建立应急运输保障机制，保证应急救援人员、物资、装备的运输需要。矿区道路必须保持畅通，重要路段必须设置应急通道。

### 7.6 经费保障
设立应急救援专项经费，保证应急救援工作的资金需要。应急救援经费专款专用，不得挪作他用。

## 第八章 培训与演练

### 8.1 应急培训
1. 定期组织员工进行应急知识培训，提高员工的应急意识和自救互救能力。
2. 新员工入职必须进行应急知识培训，考试合格后方可上岗。
3. 特种作业人员必须进行专项应急培训，掌握本岗位的应急处置技能。
4. 应急救援人员必须进行专业培训，掌握应急救援技能和装备使用方法。
5. 培训内容包括：应急预案、事故预防、自救互救、应急处置、装备使用等。

### 8.2 应急演练
1. 定期组织应急演练，检验应急预案的科学性和可操作性，提高应急救援队伍的实战能力。
2. 每年至少组织一次综合应急演练，每半年至少组织一次专项应急演练。
3. 应急演练可以采取桌面推演、实战演练等方式进行。
4. 应急演练结束后，必须进行总结评估，分析存在的问题，修订完善应急预案。
5. 应急演练必须做好记录，包括演练时间、地点、内容、参加人员、演练效果、存在问题、改进措施等。

## 第九章 后期处置

### 9.1 善后处理
1. 做好伤亡人员的医疗救治和赔偿工作。
2. 做好伤亡人员家属的安抚工作，妥善解决家属的实际困难。
3. 做好受灾人员的安置工作，保障受灾人员的基本生活。
4. 做好事故现场的清理和恢复工作，尽快恢复生产。

### 9.2 事故调查
1. 配合上级事故调查组开展事故调查工作，如实提供事故相关资料和信息。
2. 查明事故发生的原因、经过、人员伤亡和经济损失情况。
3. 认定事故性质和事故责任，提出对事故责任人的处理建议。
4. 总结事故教训，提出防范和整改措施。

### 9.3 应急总结
1. 应急救援工作结束后，必须进行全面总结评估。
2. 总结应急救援工作的经验和教训，分析应急预案存在的问题。
3. 修订完善应急预案，提高应急预案的科学性和可操作性。
4. 加强应急管理工作，提高应急救援能力。
