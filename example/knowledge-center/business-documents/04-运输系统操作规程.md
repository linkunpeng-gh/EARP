# 煤矿运输系统操作规程

## 第一章 总则

### 1.1 目的
为规范煤矿运输系统的操作行为，保障运输安全，提高运输效率，降低运输成本，制定本规程。

### 1.2 适用范围
本规程适用于煤矿地面及井下运输系统的操作，包括矿用卡车运输、皮带运输、刮板运输、轨道运输、提升运输等各种运输方式。

### 1.3 基本要求
1. 运输设备操作人员必须经过专业培训，考试合格，持证上岗。
2. 运输设备必须保持完好状态，安全保护装置齐全可靠。
3. 严格执行运输设备操作规程，严禁违章指挥、违章作业。
4. 运输线路必须保持畅通，路面质量符合要求，照明充足。
5. 建立运输设备运行记录，详细记录设备运行情况和故障处理情况。

## 第二章 矿用卡车运输

### 2.1 出车前检查
1. **车辆外观检查**：检查车身有无损伤、变形，轮胎气压是否正常，轮胎磨损是否在允许范围内，轮胎螺栓是否紧固。
2. **发动机检查**：检查机油油位、冷却液液位、燃油量，检查有无渗漏现象。
3. **液压系统检查**：检查液压油位，举升系统有无渗漏，举升缸动作是否正常。
4. **制动系统检查**：检查行车制动和驻车制动性能，制动踏板行程是否正常，制动液液位是否正常。
5. **转向系统检查**：检查转向是否灵活，有无卡滞，转向助力油位是否正常。
6. **电气系统检查**：检查灯光、喇叭、仪表、雨刮器是否正常，蓄电池电量是否充足。
7. **安全装置检查**：检查安全带、灭火器、三角警示牌、倒车报警器是否齐全有效。
8. **车厢检查**：检查车厢有无变形、裂纹，举升机构是否正常，后门闭锁是否可靠。

### 2.2 装载作业
1. 车辆到达装载点后，必须服从现场指挥人员的指挥，按照指定位置停车。
2. 停车后必须拉紧驻车制动，将变速器置于空档，发动机可以保持运转。
3. 装载机装载时，驾驶员必须密切注意装载情况，严禁将头、手伸出车外。
4. 装载必须均匀，严禁偏载、超载。矿用卡车的额定载重不得超过车辆设计载重。
5. 装载完成后，驾驶员必须检查车厢装载情况，确认无超载、偏载、撒漏后方可驶离。
6. 装载点排队等候时，必须与前车保持安全距离，严禁插队、抢道。

### 2.3 运输作业
1. 车辆起步前必须鸣笛示警，观察周围情况，确认安全后方可起步。
2. 严格按照规定的行驶路线和限速行驶，严禁超速、逆行、随意变道。
3. 矿区道路限速规定：
   - 主干道：30公里/小时
   - 次干道：20公里/小时
   - 工作面及装载点：10公里/小时
   - 弯道、坡道、交叉口：5公里/小时
4. 行驶中必须保持安全车距，前车遇有情况制动时，后车必须能够安全停车。
5. 严禁疲劳驾驶，连续驾驶不得超过4小时，每次休息时间不得少于20分钟。
6. 严禁酒后驾驶，严禁服用影响安全驾驶的药物后驾驶。
7. 行驶中严禁接打手机、与人闲谈、吃东西等妨碍安全驾驶的行为。
8. 遇有恶劣天气（大雨、大雾、大雪）时，必须降低车速，开启相应灯光，必要时停止运输作业。
9. 下坡时严禁空档滑行，必须利用发动机牵阻作用控制车速，合理使用行车制动。
10. 车辆通过交叉口、弯道、坡道时，必须减速鸣笛，注意观察，确认安全后通过。

### 2.4 卸载作业
1. 车辆到达卸载点后，必须服从现场指挥人员的指挥，按照指定位置停车。
2. 停车后必须拉紧驻车制动，将变速器置于空档。
3. 举升车厢前必须确认上方无障碍物，周围无人员，卸载点地面坚实平整。
4. 举升车厢时必须缓慢操作，严禁猛升猛降，注意观察车厢举升情况和车辆稳定性。
5. 卸载时必须将车厢举升到足够高度，确保煤炭完全卸净，严禁边走边卸。
6. 卸载完成后必须将车厢完全落下，确认举升缸完全收回后方可驶离。
7. 严禁在斜坡上举升车厢卸载，严禁在高压线下举升车厢。

### 2.5 收车后检查
1. 车辆停放到位后，必须拉紧驻车制动，将变速器置于空档，关闭发动机。
2. 检查车辆有无损伤、渗漏，轮胎有无异常。
3. 清理驾驶室和车厢，保持车辆清洁。
4. 填写车辆运行记录，记录当日运行里程、运输趟次、故障情况等。
5. 发现车辆故障必须及时报告，安排维修，严禁带病运行。

### 2.6 运输周期管理
运输周期是衡量运输效率的重要指标，包括以下组成部分：
- **装车时间**：车辆到达装载点到装载完成的时间，包括排队等待时间和实际装车时间。
- **重车运行时间**：车辆从装载点驶离到到达卸载点的运行时间。
- **卸车时间**：车辆到达卸载点到卸载完成的时间，包括排队等待时间和实际卸载时间。
- **空车返回时间**：车辆从卸载点驶离到返回装载点的运行时间。

运输周期优化措施：
1. 合理规划运输路线，缩短运输距离。
2. 优化装载点和卸载点布局，减少车辆排队时间。
3. 加强车辆维护保养，提高车辆完好率和可用率。
4. 合理配置运输车辆数量，保证运输能力与采掘能力匹配。
5. 采用智能调度系统，实时监控车辆运行状态，优化车辆调度。

## 第三章 皮带运输

### 3.1 开机前检查
1. 检查皮带机各部位连接螺栓是否紧固，机架有无变形、开焊。
2. 检查皮带接头是否完好，皮带有无撕裂、磨损、跑偏。
3. 检查托辊转动是否灵活，有无损坏、缺失，缓冲托辊是否齐全。
4. 检查滚筒包胶是否完好，滚筒有无积煤，轴承有无异响。
5. 检查减速器油位、油温，有无渗漏，联轴器连接是否可靠。
6. 检查制动装置、逆止装置是否灵敏可靠。
7. 检查清扫器是否完好，与皮带接触是否良好。
8. 检查安全保护装置是否齐全可靠，包括防跑偏保护、防打滑保护、防撕裂保护、堆煤保护、烟雾保护、温度保护、急停保护等。
9. 检查皮带机沿线有无障碍物，照明是否充足，通讯信号是否畅通。
10. 检查溜煤槽、漏斗是否畅通，有无积煤、堵塞。

### 3.2 开机操作
1. 开机前必须发出开机信号，通知沿线人员离开皮带机运转部位。
2. 确认沿线无人作业、无障碍物后，方可发出开机指令。
3. 按照逆煤流方向依次启动皮带机，即先启动下游皮带机，再启动上游皮带机。
4. 皮带机启动后，必须密切观察皮带运行情况，注意有无异响、异味、异常振动。
5. 皮带机运行平稳后，方可开始给煤。给煤必须均匀，严禁突然大量给煤。

### 3.3 运行中的检查与维护
1. 皮带机运行中，司机必须巡回检查各部位运行情况，重点检查：
   - 皮带是否跑偏，跑偏量不得超过带宽的5%。
   - 皮带接头是否完好，有无开裂、翘起。
   - 托辊转动是否灵活，有无不转、异响。
   - 滚筒有无积煤，轴承温度是否正常（不得超过75℃）。
   - 减速器油温是否正常（不得超过75℃），有无异响、渗漏。
   - 电动机温度是否正常（不得超过额定温升），有无异响。
   - 清扫器工作是否正常，皮带面是否清洁。
   - 安全保护装置是否处于正常工作状态。
2. 及时清理皮带机沿线的浮煤、杂物，保持环境整洁。
3. 严禁在皮带机运行中进行维修作业，严禁跨越运行中的皮带机，严禁乘坐皮带机。
4. 严禁用皮带机运输设备、材料、人员等非煤炭物品。
5. 发现皮带跑偏时，必须及时调整，调整方法：
   - 检查滚筒、托辊是否粘煤，及时清理。
   - 调整跑偏侧的调心托辊。
   - 检查皮带接头是否正，必要时重新接头。
   - 检查装载点是否偏载，调整给煤位置。

### 3.4 停机操作
1. 正常停机必须按照顺煤流方向依次停机，即先停止上游给煤，待皮带上的煤炭运净后，再依次停止各台皮带机。
2. 停机前必须将皮带上的煤炭运净，严禁带负荷停机。
3. 停机后必须切断电源，闭锁开关，悬挂"有人工作，禁止合闸"警示牌。
4. 清理皮带机及周围环境卫生，填写运行记录。

### 3.5 紧急停机
遇到下列情况之一时，必须立即紧急停机：
1. 皮带严重跑偏，有撕裂危险时。
2. 皮带接头开裂、有断裂危险时。
3. 皮带打滑、冒烟、有焦糊味时。
4. 电动机、减速器、轴承温度急剧升高或有异响时。
5. 发生人身事故或有人员受伤时。
6. 皮带机上方有物体坠落，可能损坏皮带时。
7. 发生火灾、水灾等灾害时。
8. 安全保护装置动作时。

紧急停机后，必须查明原因，排除故障，确认安全后方可重新开机。

## 第四章 运输系统安全管理

### 4.1 人员安全
1. 运输系统作业人员必须穿戴好劳动防护用品，安全帽、工作服、防护鞋等必须齐全。
2. 严禁在运输设备运行中进行维修、清理、加油等作业。
3. 严禁跨越运行中的运输设备，严禁乘坐运输设备。
4. 运输设备检修时必须严格执行停电、闭锁、挂牌制度，设专人监护。
5. 运输线路沿线必须设置足够的照明和安全警示标志。

### 4.2 设备安全
1. 运输设备必须定期检查、维护、保养，保证设备完好。
2. 安全保护装置必须齐全可靠，定期试验，严禁拆除或短接安全保护装置。
3. 运输设备的制动系统必须灵敏可靠，定期检查制动性能。
4. 运输设备的电气系统必须符合防爆要求，电缆悬挂整齐，接线盒完好。
5. 建立设备台账和维修记录，详细记录设备运行、维修、故障情况。

### 4.3 环境安全
1. 运输线路必须保持畅通，路面平整，无积水、无杂物。
2. 运输线路两侧必须设置安全护栏，防止车辆坠落。
3. 装载点、卸载点必须设置足够的照明和警示标志。
4. 运输线路交叉口、弯道、坡道必须设置反光镜和减速带。
5. 定期清理运输线路的浮煤、杂物，保持环境整洁。

## 第五章 运输系统常见故障及处理

### 5.1 矿用卡车常见故障

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 发动机不能启动 | 蓄电池电量不足/燃油不足/启动电机故障/点火开关故障 | 充电或更换蓄电池/补充燃油/检修启动电机/检修点火开关 |
| 发动机过热 | 冷却液不足/散热器堵塞/风扇皮带松弛/节温器故障 | 补充冷却液/清洗散热器/调整风扇皮带张紧度/更换节温器 |
| 制动失灵 | 制动液不足/制动管路渗漏/制动片磨损严重/制动总泵故障 | 补充制动液/检修制动管路/更换制动片/检修制动总泵 |
| 转向沉重 | 转向助力油不足/转向助力泵故障/转向拉杆卡滞/轮胎气压不足 | 补充转向助力油/检修转向助力泵/润滑转向拉杆/补充轮胎气压 |
| 车厢不能举升 | 液压油不足/液压泵故障/举升缸密封损坏/操纵阀故障 | 补充液压油/检修液压泵/更换举升缸密封/检修操纵阀 |

### 5.2 皮带机常见故障

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 皮带跑偏 | 滚筒粘煤/托辊不转/接头不正/装载偏载/机架不正 | 清理滚筒/更换托辊/重新接头/调整给煤位置/校正机架 |
| 皮带打滑 | 皮带张紧度不够/滚筒包胶磨损/皮带过载/滚筒有水 | 调整张紧力/更换滚筒包胶/减少给煤量/清理滚筒积水 |
| 皮带撕裂 | 皮带接头开裂/尖锐物体划伤/跑偏磨边/托辊脱落划伤 | 重新接头/清除尖锐物体/调整跑偏/更换托辊 |
| 减速器异响 | 齿轮磨损/轴承损坏/缺油/润滑油变质 | 更换齿轮/更换轴承/补充齿轮油/更换齿轮油 |
| 电动机过热 | 过载/通风不良/轴承损坏/电压异常 | 减少负荷/清理通风道/更换轴承/检查电源 |
