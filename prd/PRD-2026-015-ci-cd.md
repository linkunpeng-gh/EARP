## 1. 背景

EARP 当前无 CI/CD——测试依赖本地手动运行。需要 GitHub Actions 实现 push/PR 自动测试。

## 2. 范围

### 2.1 覆盖

| 内容 | 说明 |
|:-----|:-----|
| 测试矩阵 | 4 个 SDK 包全部运行（core/connector/runtime/plugin） |
| 触发条件 | push to main + PR to main |
| Python 版本 | 3.12（匹配 requires-python） |
| 依赖安装 | pip install -e 各 SDK 包 + cryptography |
| 测试命令 | pytest --tb=short 覆盖全部 tests/ |
| 失败处理 | 任一包测试失败 → CI ❌ |

### 2.2 不做（后续）

- Docker 镜像构建
- 部署到 staging/prod
- Linter/type checker
- 覆盖率报告

## 3. 验收条件

| ID | 描述 |
|:--:|:-----|
| AC-01 | `.github/workflows/test.yml` 存在，push/PR 触发 |
| AC-02 | 4 个 SDK 包全部安装并运行测试 |
| AC-03 | 一次 CI 运行覆盖全部 193+ tests |
| AC-04 | 文件结构与 EARP monorepo 一致（pip install -e libs/...） |

## 4. 产出物

`.github/workflows/test.yml` — 单文件 GitHub Actions workflow
