## Variant: Sidebar Dense

### Design stance
Developer-tool dashboard — compact left sidebar navigation, dense data-first layout. Every pixel earns its place.

### Key choices
- Layout: fixed left sidebar (200px) + fluid content area
- Typography: Inter 510 weight navigation, small captions for metadata
- Color: Linear dark — #08090a root, border-subtle separators
- Interaction: sidebar hover → bg lift; CTA button accent color

### Trade-offs
- Strong at: vertical space efficiency, familiar IDE/tool pattern, many nav items
- Weak at: horizontal space constrained by sidebar, no top-level branding prominence

### Best for
Power users who navigate between 5+ sections frequently. Developers debugging Plan→Invoke→Audit chains.
