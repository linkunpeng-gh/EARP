## Variant: Topnav Fluid

### Design stance
Platform dashboard — top navigation bar, full-width content, action-card driven. Feels like a cloud console.

### Key choices
- Layout: sticky top header + centered max-width (1200px) main content
- Typography: larger h2 (1.5rem), subtitle for context
- Color: Linear dark — elevated surface cards with hover accent borders
- Interaction: quick-action cards with hover border transition; top nav with accent underline

### Trade-offs
- Strong at: spacious, readable, clear visual hierarchy, good for occasional users
- Weak at: vertical space consumed by header + padding, navigation items limited before wrapping

### Best for
Infrequent admin users who need clear visual guidance. Managers checking audit logs or creating sessions occasionally.
