Catalog 治理

暂无可展示的 Catalog 引用

统一查看只读聚合权威源对象；待源系统列表 API 和真实引用注册就绪后显示。

注册权威源引用

只提交来源系统和精确版本；canonical input 与权威 hash 由服务端 Adapter 获取并独立复算。

新建 Pack 草稿

Pack 只保存已注册引用的指针；语义内容仍由权威源系统维护。首次创建默认版本为 1.0.0。

向草稿加入已注册引用

只能选择已注册的精确引用；Hash 由服务端从 Catalog pin 读取，客户端不能提交 Hash。

暂无 Pack

Pack 导入属于 Phase 2；Phase 1 只允许通过治理 API 生成、发布和导出不可变版本。

生成 Manifest 预览

输入已发布 Pack，服务端按三层冲突规则组合引用。签署由外部治理流程完成，页面只提交签署结果。
