## 一、品牌视觉规范（用户确认）

| 项 | 值 |
|---|---|
| 风格 | 极简企业商务白底、大留白、卡片式布局，避免花哨特效与卡通插图 |
| 主色 | `#0047AB` 钴蓝 |
| 辅助色 | `#2563EB` 亮蓝 |
| 点缀色 | `#E67E22` 暖橙（仅用于价值数字与结论） |
| 字体 | 思源黑体（Source Han Sans SC / Noto Sans CJK SC） |
| 版式 | 16:9（13.33" × 7.5"） |
| 标题原则 | 输出价值结论，拒绝纯名词标题 |

## 二、内容规范

- 规避纯技术晦涩术语，兼顾新手伙伴认知度与企业客户专业性
- 所有功能遵循五要素：「是什么功能 + 适配什么场景 + 落地案例 + 解决什么痛点 + 业务价值」
- 案例：真实工业制造案例（供应链：库存调拨/多系统对账/物流改派；生产运营：预测性维护/产销协同）标注"客户实践"；政务/交通等补齐案例标注"示例场景"
- 数据中台协同场景（可信问数/智能归因/洞察预测/一言成报/智策看板 + 大模型×BI引擎双核驱动）为核心卖点
