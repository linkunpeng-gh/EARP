# 应用中心（智能体）前端人工测试方案

**版本**：2026-08-24 ｜ **范围**：admin 端（earp-admin） ｜ **前置**：dev 环境起（API 8000 + DB 到 0029）、以 admin 角色登录

## 0. 准备（一次）

1. 确认 DB 迁移到 head（`make migrate`），重启 API。
2. 打开 admin 首页 → 左侧导航应显示：
   - 工作台：chat / chatflow
   - 应用中心：**智能体**
   - 治理中心：Audit / Roles / **应用分类** / **应用权限**
3. 在治理中心 → 应用分类确认默认词表存在：财务、人事、客服、IT 运维、数据分析、其他。

---

## 1. 智能体列表（apps.html）

| # | 步骤 | 预期 |
|---|------|------|
| 1.1 | 进入「应用中心 → 智能体」 | 只显示**已发布**应用；草稿不出现；卡片含 名称/描述/类型徽标(chat/chatflow)/分类/标签/创建人/收藏数 |
| 1.2 | 搜索框输入名称关键词（如「报销」） | 列表实时过滤（名称匹配） |
| 1.3 | 搜索「u1」（创建人 user_id） | 匹配创建人的应用 |
| 1.4 | 搜索标签词（如「制度」） | 匹配标签 |
| 1.5 | 分类下拉选「财务」 | 只显示财务分类应用 |
| 1.6 | 类型筛选选「chatflow」 | 只显示 flow 应用 |
| 1.7 | 排序切「最热（收藏数）」 | 收藏数多的排前 |
| 1.8 | 切「我的应用」Tab | 显示当前用户收藏的应用（无收藏时显示空态提示） |

## 2. 收藏（我的应用）

| # | 步骤 | 预期 |
|---|------|------|
| 2.1 | 点卡片右上 ⭐（☆→★） | 收藏成功；「我的应用」Tab 出现该应用 |
| 2.2 | 再点 ★（取消） | 取消成功；「我的应用」里消失 |
| 2.3 | 运行页里点「☆ 收藏」 | 收藏成功并更新按钮状态 |

## 3. 运行（chat 智能体，抽屉）

| # | 步骤 | 预期 |
|---|------|------|
| 3.1 | 点一个 chat 应用卡片 | 右侧抽屉滑出，标题/类型/分类正确 |
| 3.2 | 输入消息发送 | 回复**逐字流式**出现（SSE） |
| 3.3 | 连发两条 | 第二条在同一会话续接（上下文有效） |
| 3.4 | 点「✕」关抽屉再开 | 会话重置（新会话） |

## 4. 运行（chatflow，抽屉 + 全屏页）

| # | 步骤 | 预期 |
|---|------|------|
| 4.1 | 点一个 chatflow 应用卡片 | 抽屉打开；发送消息 |
| 4.2 | 观察「节点执行过程」面板 | 逐节点 node_start（⏳）→ node_end（✓ + 耗时）；LLM 节点 token **逐字流式**；条件分支显示「→ 分支 xx: then/else」 |
| 4.3 | 含 human_approval 的 flow | 面板出现「⏸ 等待确认」+ 确认/拒绝按钮；点确认 → 恢复执行至完成 |
| 4.4 | 点「⛶ 全屏」 | 进入 run.html；左栏出现会话历史（当前应用 + 当前用户） |
| 4.5 | 全屏页新建会话 / 切换历史 | 消息区切换正确；历史消息完整 |
| 4.6 | 全屏页发送 | 流式 + 节点面板表现与抽屉一致；完成后会话列表刷新 |

## 5. 工作台发布表单

| # | 步骤 | 预期 |
|---|------|------|
| 5.1 | chat 编辑页（chat-edit.html） | 配置区有「业务分类」下拉（词表数据）与「标签」输入 |
| 5.2 | 填分类/标签 → 保存 → 发布 | 发布弹窗预填分类/标签；可修改；**不选分类点发布** → 拦截提示「请选择业务分类」 |
| 5.3 | 选分类发布 | 成功；应用中心可见（分类/标签正确） |
| 5.4 | chatflow 编辑页同样操作 | 发布弹窗含分类/标签；不选分类拦截；发布后应用中心可见 |
| 5.5 | 编辑已发布应用 → 保存 | 回到草稿；应用中心列表消失；重新发布后回来 |

## 6. 治理中心 · 应用分类

| # | 步骤 | 预期 |
|---|------|------|
| 6.1 | 新增分类「测试分类」 | 出现在列表；应用中心筛选下拉同步出现 |
| 6.2 | 把某应用分类改为「测试分类」→ 在应用分类页改名 | **已发布应用的分类同步更新**（应用中心卡片上能看到新名） |
| 6.3 | 删除被引用分类 | 提示「N 个应用的分类已置空」；应用中心对应应用分类变空 |
| 6.4 | 删除未被引用分类 | 直接删除 |
| 6.5 | 重名新增/改名 | 被拒（409） |

## 7. 治理中心 · 应用权限矩阵

| # | 步骤 | 预期 |
|---|------|------|
| 7.1 | 矩阵页 | 行=非 admin 角色、列=已发布应用；应用搜索可用 |
| 7.2 | 勾选某应用的某个角色 → 保存 | 该应用模式变「白名单」（restricted）；**未勾选角色登录看不到** |
| 7.3 | 用 admin 角色查看 | 白名单应用仍可见（admin 兜底） |
| 7.4 | 取消全部勾选 → 保存 | 模式回「开放」；所有人可见 |
| 7.5 | 在 Roles 页删除白名单应用的唯一角色 | 该应用保持 restricted（fail-closed）——非 admin 均不可见；重新勾选角色后恢复 |
| 7.6 | 保存后刷新矩阵页 | 勾选状态与模式持久化正确 |
